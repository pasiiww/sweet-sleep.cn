# 饮品推荐初始清单

初始清单供群聊 `/今天喝什么` 随机抽取，按品牌官网近期主推、官方热门/经典单品及长销代表作整理。它不是跨品牌销量排名；官网菜单会按城市、门店和季节变化，后台管理员可以随时增删改，建议按群友实际能买到的门店维护。

当前覆盖：蜜雪冰城、霸王茶姬、古茗、奈雪的茶、CoCo都可、1点点、茶百道、沪上阿姨、喜茶、茶颜悦色、茉莉奶白、Tenjoy柠檬奶、柠檬向右。列表初始值在 `answers.DEFAULT_DRINK_MENU`。

## 维护建议

新增时尽量填品牌和清晰的完整品名，避免放入过期联名或短时限定；若希望某品牌出现在随机结果里的机会更高，可以给它维护更多候选饮品。改完后台清单后，机器人最多缓存旧列表 30 秒。

每项还可标注“冷饮 / 热饮 / 冷热都可”，天气推荐只从匹配温度和“冷热都可”的项目里选择。杭州天气接入和风天气每日预报接口；项目需要在「饮品推荐」后台配置自己的 API Host 与 API Key。和风天气免费订阅有日调用额度并要求产品注明来源，机器人成功读取天气时会显示来源链接。每日预报 API 不返回昨日实况，服务端保存每次取得的杭州当日最高温预报，下一日可据此比较趋势；首次无昨日记录时使用随机策略。
